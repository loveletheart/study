# 온도 — 날씨를 입는 일상

Vue 3와 TypeScript로 만든 날씨·옷차림 MVP 화면입니다. 지역 검색 → 날씨 확인 → 오늘 또는 주간 추천 → 취향 반영 흐름을 제공합니다.

## 실행

Node.js 20.19 이상(20.x) 또는 22.12 이상이 필요합니다. 현재 PC의 Node.js 24.11에서도 실행·빌드할 수 있는 Vite 7을 사용합니다.

먼저 프로젝트 루트에서 백엔드를 실행합니다.

```powershell
.\run.cmd
```

별도 터미널에서 프론트엔드를 실행합니다.

```powershell
cd frontend
npm ci
npm run dev
```

화면: **http://127.0.0.1:5173/app/**

개발 서버는 `/api` 요청을 기본 `http://127.0.0.1:8000`으로 전달합니다. 백엔드 포트를 바꿨다면 프론트 실행 터미널에서 설정합니다.

```powershell
$env:STUDY_API_TARGET = 'http://127.0.0.1:8001'
npm run dev
```

서버의 VWorld·LLM 비밀 설정은 프로젝트 루트 `.env`에서 관리합니다. API 키를 프론트엔드나 `VITE_` 환경변수에 넣지 않습니다. 개발 서버는 로컬 컴퓨터에서만 열립니다.

## 백엔드 하나로 화면 제공

```powershell
cd frontend
npm ci
npm run build
cd ..
.\run.cmd
```

빌드 후 백엔드를 시작하거나 재시작하면 **http://127.0.0.1:8000/app/** 에서 화면을 제공합니다. Node.js는 빌드에만 필요합니다. 기존 `/`, `/health`, `/docs`, `/api/v1/*` 경로는 유지합니다. `frontend/dist`는 Git에 포함하지 않으므로 새로 받은 PC에서도 빌드가 필요합니다.

`npm run preview`는 빌드 결과를 http://127.0.0.1:4173/app/ 에서 로컬 확인합니다. 배포용 서버가 아닙니다.

## 제공하는 흐름

- 지역명·별칭·상위 지역의 포함 검색과 동명 지역 구분. `서울 강남`처럼 공백으로 검색어를 결합할 수 있으며 전체 건수와 20개씩 더 보기를 제공. 검색 중·결과 없음·추가 조회 실패·키워드 변경 시 이전 응답 제외 안내.
- 현재 기온·체감온도·습도·바람, 오늘 최저·최고, 최대 강수확률, 시간별 예보.
- 시군구 공유 API 기반 추천 의류·선정 이유·주의사항과 피할 옷차림.
- 원피스/점프수트와 상하의 조합을 구분하며 `null`은 표시하지 않음.
- 7일 날씨·날짜별 추천·주간 준비 의류, 배치 미준비 안내.
- 체감 추위·선호 스타일·활동 조건, 선호 의류와 피할 의류는 적용 버튼을 누를 때 요청에 반영.
- 이메일·비밀번호 회원가입과 로그인, 가입 후 추천 프로필 설정 화면 제공.
- 로그인하면 지역·추천 조건을 서버 계정에 저장하고 재로그인 시 복원. 비로그인은 `ondo.settings.v1` 브라우저 저장소에 별도 저장.
- 프로필 저장 실패는 입력을 유지하며 성공한 뒤 추천에 반영. 로그아웃은 서버 세션을 폐기하고 둘러보기 설정으로 전환.
- 날씨와 추천을 별도 요청하여 느린 모델 응답이 날씨 표시를 막지 않음.
- 지역·기간·취향 변경 시 이전 요청을 취소하고 이전 결과가 새 화면을 덮어쓰지 않음. 서버에서 이미 시작된 모델 추론까지 취소되는 것은 아님.
- 외부 실패 시 임의의 날씨나 추천을 보여주지 않음. 재시도는 사용자가 버튼으로 실행.
- PC·모바일 대응, 키보드 탐색·대화상자·상태 안내·동작 줄이기 지원.

화면의 옷 이미지는 의류 구성과 완전히 일치하는 상품 이미지가 아닌 예시 일러스트입니다. 실제 추천은 옆의 의류 목록을 확인합니다. Google Fonts를 불러오지 못하는 환경에서는 시스템 글꼴로 표시합니다.

## 기존 정책과의 관계

오늘 추천은 최초 생성 시 시간이 필요합니다. 화면의 대기 문구는 진행률이나 완료 시각을 보장하지 않습니다. 새로고침은 저장된 추천을 재조회하며 강제 재생성을 요청하지 않습니다.

주간은 요청으로 즉시 만들지 않습니다. `OUTFIT_WEEKLY_NOT_READY`는 준비 안내로 표시합니다. 새 지역·개인 조건은 다음 배치 대상으로 등록되며, 새벽 1~2시는 시작 시간대입니다. 완료 시각은 작업량에 따라 달라집니다. 준비된 추천은 이전 예보 기준일 수 있어 기준 날짜·생성 시각·날씨 조회 시각을 표시합니다. 최신 날씨와 추천의 날씨 기준은 다를 수 있습니다.

`/app/#login`에서 로그인, `/app/#signup`에서 회원가입, `/app/#profile`에서 추천 프로필을 편집합니다. 이메일·비밀번호·닉네임으로 가입하고 지역·체감 온도·스타일·활동을 설정합니다. 선호 의류(제한 없음·남성복 위주·여성복 위주)와 피할 의류(치마·원피스·반바지·샌들·굽 높은 신발·민소매)는 선택 사항입니다. 계정 정보는 추천 모델로 전송하지 않으며, 서버의 HttpOnly 쿠키로 로그인 상태를 유지합니다.

이메일 인증·비밀번호 재설정·소셜 로그인, 검증된 의류 DB, 모델 학습, 추천 내용의 의미 검증·재생성, 배치 복구, Redis와 작업 큐는 포함하지 않습니다. 선택한 의류 제외 조건은 모델 입력에 반영하며 실제 결과의 준수 여부는 별도 품질 검증이 필요합니다. 인증 API·저장 구조·HTTPS 설정은 [사용자 기능 문서](../backend/app/users/README.md)를 참고하세요.

## 검증

```powershell
npm run build
npx playwright install chromium
npm run test:e2e
```

브라우저 시험은 PC·모바일에서 API 계약에 맞춘 합성 응답을 사용합니다. 운영 DB·VWorld·날씨 제공사·로컬/유료 모델을 호출하지 않습니다. 실제 추천 품질 또는 외부 서비스의 정상 여부를 보장하는 시험은 아닙니다. 스크린샷과 실패 추적은 Git에서 제외한 `test-results`에 저장합니다.

`src/api.ts`는 공통 응답을 처리하고 `src/composables/useWardrobe.ts`는 추천 조회 상태, `useAccount.ts`는 로그인·프로필 저장을 관리합니다. `src/components`는 역할별 화면 요소이며 `src/App.vue`가 조회와 계정 화면 흐름을 구성합니다. 프로필 URL은 정적 서버에서도 동작하도록 해시를 사용합니다.
